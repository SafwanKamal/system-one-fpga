# Recovering an exact KV prefix on an embedded FPGA

Repository review and research decision, November 4, 2026

## Decision

Study whether an interrupted inference request can retain an **exact, batch-aligned KV prefix in the existing single DDR bank on KR260**, then replay only the uncertain suffix. Start with cooperative interruption at completed decoder-command boundaries while the same service, exclusive lease and hardware generation remain live. Qualify the actual write boundary before claiming recovery. Compare the result with throwing away the cache after cancellation and with the normal v16 happy path.

The paper-sized question is whether a small completion and ownership contract can make this recovery exact, measurably reduce time to a matching answer after an interruption, and avoid copying hundreds of MiB of KV. Existing work already covers exact prefix reuse, rollback by truncation, checkpointed serving and AXI timeouts. The candidate contribution is the implementation and evidence at the PS–PL boundary of a shared-DDR embedded decoder, including where reuse has to stop. [SGLang](https://arxiv.org/html/2312.07104v2) · [Aborted but Not Forgotten](https://arxiv.org/html/2608.15939v1#S4) · [Concordia](https://arxiv.org/abs/2606.23521) · [AXI isolation precedent](https://retis.sssup.it/~a.biondi/papers/FCCM2020.pdf)

## First experiment

### 1. Qualify the fence offline

The current `command()` requires idle before launch, does an ioctl and MMIO launch, polls the HLS done bit, then reads a status word. The scratch tag is written by the host and the work counters increment in the host after returns. The HLS source writes KV in a layer/head/position layout, and attention limits visible positions causally. Packaged generated Verilog and a hash inventory are available locally. Inspection of the state AXI adapter found `in_BUS_BRESP` and `in_BUS_RRESP` connected to submodules but unused beyond their input declarations in those submodules. Treat transport errors as requiring independent observation. This is a source observation. Retirement and visibility still require an interface test. [Runtime](../../src/sysone/v2/qwen_fpga_runtime_v16.py) · [HLS](../../hls/qwen_decoder_v9d/qwen_decoder.cpp) · [Generated RTL inventory](../../build/v2/qwen-fpga-decoder-v9d/ip-rtl-consistency.json) · [State AXI adapter](../../build/v2/qwen-fpga-decoder-v9d/hls-release/solution/impl/ip/hdl/verilog/qwen_decoder_state_m_axi.v)

The smallest useful test is a simulation of the packaged write path with final B delayed and RLAST backpressured. Trace launch, done, last successful response, outstanding counts, write address/size/strobes, and the next read. Include independent AW and W handshakes, outstanding IDs, queued work, a non-OKAY response and a stale completion. Check the CDC/SmartConnect and PS memory visibility assumptions separately. A new RTL monitor is justified only if the existing boundary cannot give the evidence. A quiet bus sample has no authority by itself.

ABI2's `SYNC_COMMAND` is a pre-launch `dma_wmb()`. It does not supply a completion receipt. The generated state adapter defaults its cache attributes to `0011`. Check the final implemented path's attributes and the ordering/visibility guarantee at the next actual reader rather than equating a B handshake at any probe point with DDR visibility everywhere. [ABI2 driver](../../firmware/qwen_dma_v2/sysone_qwen_dma_v2.c) · [Arm AXI ordering specification](https://community.arm.com/cfs-file/__key/communityserver-discussions-components-files/476/IHI0022H_5F00_amba_5F00_axi_5F00_protocol_5F00_spec.pdf)

### 2. Model the recovery invariant

Keep a trusted in-memory watermark `c` in the same boot, overlay/reset epoch, model generation, scratch lease and conversation. At each restart, the reusable range is bounded by `c`, the longest exact prefix of the new input and the final-logit replay requirement. Align down to the existing eight-token boundary. Shrink the old commitment before issuing a divergent suffix write. Advance it only for complete all-layer groups with successful retired traffic and visible writes. A cancelled attempt may leave some layers of the next group populated. The resumed prefill reinitializes temporary activation and selection state, writes that group again, and always recomputes final logits.

Check that writes for every launched suffix cannot touch committed positions, and that no future read attends to stale positions at or after the watermark before they are overwritten. Compare committed KV and the first resumed logits on diagnostic runs, plus all generated IDs against the same-image fresh prefill oracle. Poison the abandoned suffix and include shortened prompts, changed tokens before and after the boundary, 7/8/9-token alignment cases, 1,024-context edges and different session IDs. The proof target is scoped publication and reuse of valid cache state. Exact sampled outputs on a finite test set are a separate measured result.

### 3. Run a paired cancellation pilot

Use seeded short, medium and long fitting prompts and an independent, pinned subset of public BFCL multi-turn or ToolSandbox episodes that fit the context budget. Count rejects. If trace conversion changes prompts or tool catalogs, report the adaptation and score this as trace replay. Use scripted read receipts and a fixed oracle for paired timings. Block-randomize the arms within each session and prime or clear cache according to policy. Record cut point and interruption-detection time. Keep model, tokenizer, bitstream, clocks, context, output reserve, host and ABI2 verification policy identical.

| Arm | Treatment |
|---|---|
| Full replay | Within the same resident harness, invalidate the KV cache on interruption and re-prefill the retry. This isolates the policy cost. |
| Existing v16 | Capture the healthy and cache-off controls and the actual fault lifecycle, including any service restart and startup verification. Report these costs separately from the policy-only comparison. |
| Committed prefix | Retain the qualified aligned prefix and replay the suffix within the live lease. Compare preservation of the old prefix with advancing through newly completed groups. |
| Optional copied prefix | Copy/restore only the valid prefix to a measured host buffer as a cost reference if available within the memory budget. |

Cut before launch, after a completed group, between layer commands, and before result publication. Keep the initial fault cases before any external tool dispatch. v16 calls the tool after cache commit, so a service error around tool execution does not resolve whether an effect already occurred. For in-flight timeout or uncertain process death, reset, new overlay, generation change or late response, mark the cache unusable. Cold restart only after verified drain or platform reinitialization. A broader claim requires a proven reset/drain protocol and a separate routed candidate with injected faults on the physical path. Count unresolved quarantine separately from successful retry. [v16 service sequence](../../src/sysone/v2/qwen_arm_service_v16.py)

Primary outcomes are exact parity and time from interruption detection to a complete matching response, including failed retries and misses. Report saved groups/weight passes, cache occupancy vs physical allocation, retry and uninterrupted p50/p95, empirical worst cases, and availability under unknown completion. Sweep interruption frequency as a sensitivity parameter. Use paired uncertainty across independent episodes and report actual experimental cut points and denominators. If a candidate adds an RTL monitor, report timing, resources and CDC checks. Energy can be an extension after whole-board instrumentation is qualified.

### Go/no-go

Proceed to a new routed design only if the pilot can demonstrate a real preservation opportunity and a reproducible recovery benefit over full replay at the same verification policy. A suggested development gate is zero unexplained KV or generated-ID divergence across the qualified cells, plus at least one independently selected workload stratum with a material paired recovery improvement and no material steady-state penalty. Freeze numeric engineering thresholds using development data before collecting the held-out run. If fence/visibility cannot be qualified, stop at trace characterization and the existing prefix demo. If only cooperative cuts can be qualified, describe exactly that scope. A process restart, overlay reset or power loss belongs to a different recovery contract.

The bounded maintenance effect gate remains a separate direction contingent on independently authored capability evidence. A successful cache study can serve the current typed or generated tool workload and any future stronger proposer without conflating these questions.
