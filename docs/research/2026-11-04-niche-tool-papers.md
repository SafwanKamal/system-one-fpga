# Tool use, structured generation and semantic parsing

November 4, 2026. This targeted review covers 43 distinct primary research papers. It prioritizes work that can change the interpretation of System One's command, tool-call, and maintenance results or the design of its board workload. Entries are primary-source abstract screens unless marked **selected sections**, which indicates that I also checked the relevant method, evaluation, or limitations passage. Years use first public paper date unless a proceedings source is linked. Results are authors' reports on their stated tasks. The set is a relevance screen with no claim of exhaustive retrieval.

The repo provides three distinct anchors. The R5 MiniLM path has on-board intent and slot results from existing public test splits. The software-only November 2/4 Qwen capability and maintenance campaigns found strong general-call results alongside weak conditional planning, including 4/64 correct conditional plans for the best interactive head and 102 wrong schema-valid plans across the 184-case maintenance set. The v9d on-board trace has matched greedy generated IDs with exact-prefix reuse on the frozen workload. These are separate measurements with separate target populations. ## Stateful tool evaluation and failure handling

- **T01. The Berkeley Function Calling Leaderboard (BFCL): From Tool Use to Agentic Evaluation of Large Language Models (2025).** **Selected sections.** BFCL combines static AST comparisons, crowd-sourced calls, curated multi-turn suites and agentic tasks. Its taxonomy separates parallel calls, missing function/parameter behavior and context maintenance. The local 200-call Python subset measures its pinned categories. Use frozen multi-turn trajectories as a second board trace and report coverage separately from BFCL scores. [ICML paper](https://openreview.net/pdf/d52a12bb32128210600246f8979d90b892505cca.pdf)
- **T02. ToolSandbox: A Stateful, Conversational, Interactive Evaluation Benchmark for LLM Tool Use Capabilities (2024).** Dynamic milestones score intermediate and final states across valid trajectories. Implicit dependencies, insufficient information and canonicalization challenged capable models. Its milestone scheme would catch a read performed after a dependent write and offers independent receipt sequences for trace replay. [Paper](https://arxiv.org/abs/2408.04682)
- **T03. τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains (2024).** The benchmark scores final database state and consistency across repeated trials, exposing failures missed by one-shot success. Import the distinction between per-request and all-turn correctness. The first score for a board replay should be token parity, with episode success reserved for real simulated state transitions. [Paper](https://arxiv.org/abs/2406.12045)
- **T04. τ²-Bench: Evaluating Conversational Agents in a Dual-Control Environment (2025).** Introducing a second actor who can mutate shared state materially reduced success compared with no-user settings. Its compositional task generator motivates independent state-change traces. The local two-turn sensor-message pilot holds the plant simulated and has no independent user acting in the world. [Paper](https://arxiv.org/abs/2506.07982)
- **T05. Beyond Function Calling: Benchmarking Tool-Using Agents under Tool-Environment Unreliability (2026).** **Selected sections.** ToolBench-X injects five kinds of recoverable tool and environment hazard and validates that a recovery path still produces the reference answer. Diagnostic hints recovered more accuracy than additional interaction rounds in its ablation. Its failure axis is tool behavior. A board timeout while a DMA owner can still write is a different fault axis, with a different oracle. [Paper](https://arxiv.org/html/2606.25819)
- **T06. AgentAbstain: Do LLM Agents Know When Not to Act? (2026).** **Selected sections.** Paired act/abstain tasks perturb instruction, tool or state and score actual commit alongside a response judge. The strongest tested agent got 59.5% correct on both halves of a pair. Its post-hoc abstention cases show why emitted text and executed state must be scored separately. Paired stop conditions already have a clear precedent. [Paper](https://arxiv.org/html/2607.10059)
- **T07. DelegationBench: Measuring When AI Agents Should Ask Before Acting (2026).** **Selected sections.** It distinguishes action, permission requests, requests for missing data and refusal. A keyword rule written after seeing the benchmark outscored eight models in agreement while changing decisions on just 9/48 matched pairs. The local perfect authored-rule result likewise needs prospective held-out language families and pair responsiveness to support a transfer claim. [Paper](https://arxiv.org/html/2610.05532)
- **T08. Gecko: A Simulation Environment with Stateful Feedback for Refining Agent Tool Calls (2026).** Combines tool/argument checks, simulated schema- and state-consistent responses, and task-completion feedback. Refining proposed calls in this environment improved BFCLv3 and τ²-bench results. A pinned mock plant already implements a simpler feedback source locally. A board trace can hold receipts fixed and isolate exact retry without requiring model-directed repair. [Paper](https://arxiv.org/abs/2602.19218)
- **T09. API-Bank: A Comprehensive Benchmark for Tool-Augmented LLMs (2023).** Its executable tools and annotated dialogues distinguish call formation, API retrieval and planning. The paper's adapted Lynx substantially improves over its Alpaca base. The separation helps interpret the repo's better general call counts alongside weak conditional maintenance. [Paper](https://arxiv.org/abs/2304.08244)
- **T10. StableToolBench: Towards Stable Large-Scale Benchmarking on Tool Learning of Large Language Models (2024).** Virtualizing external tool responses and stabilizing evaluation reduces run-to-run dependence on API availability. Pin a receipt corpus and scorer for local comparison, and report a real closed-loop mock as a separate experiment because frozen replay holds the state trajectory constant. [Paper](https://arxiv.org/abs/2403.07714)

## Compact tool models and action interfaces

- **T11. TinyAgent: Function Calling at the Edge (2024).** Adapts 1.1B and 7B models, retrieves relevant tools to shorten input, and demonstrates a local MacBook assistant using quantization. A relevant model/system control for prompt reduction. Tool pruning must be evaluated separately from exact token-prefix reuse because pruning changes what the model sees. [Paper](https://arxiv.org/abs/2409.00608)
- **T12. Extending FunctionGemma for Practical On-Device Mobile Function Calling (2026).** **Selected sections.** Completion-only adaptation of 270M FunctionGemma improves exact synthetic Android call accuracy from 29.3% to 76.5% on the extended catalog. The combined model gives up some accuracy on the original suite for wider coverage. A close comparison for the local FunctionGemma specialization, limited to synthetic, single-turn Android calls. [Paper](https://arxiv.org/html/2609.25373)
- **T13. Beyond Fluent Generation: A CPU Reliability Benchmark for MCP-Style Tool Calling in Sub-2B Small Language Models for Edge Deployment (2026).** A recovery parser yields much better scores than strict raw JSON parsing across five small models. The strict audit found 5/1,000 directly parseable outputs. Explicit tool and value cues limit the semantic challenge. Retain separate strict transport, normalized transport and exact semantic results in the local tests. [Paper](https://arxiv.org/abs/2609.07370)
- **T14. Hammer: Robust Function-Calling for On-Device Language Models via Function Masking (2024).** Trains compact function callers with masked naming cues and irrelevant-tool examples. Evaluations motivate alias permutations and near-neighbor distractors for the repo's catalog. Success on unseen names would be separate evidence from conditional operator or receipt grounding. [Paper](https://arxiv.org/abs/2410.04587)
- **T15. xLAM: A Family of Large Action Models to Empower AI Agent Systems (2024).** A unified training and data-synthesis pipeline improves action-model benchmark results across dense and MoE scales. Its 1B-class specialization makes the model line a relevant capability baseline. The local Q4 screen used a second-generation release with a different checkpoint, runtime and budget. [Paper](https://arxiv.org/abs/2409.03215)
- **T16. APIGen-MT: Agentic Pipeline for Multi-Turn Data Generation via Simulated Agent-Human Interplay (2025).** Builds verified task blueprints and realizes them as agent–user trajectories to train xLAM-2-fc-r. Its small models sometimes surpass larger counterparts in the tested multi-turn settings. Blueprint validation and independently authored test trajectories are transferable to the local 800 teacher-forced turns. [Paper](https://arxiv.org/abs/2504.03601)
- **T17. ToolACE: Winning the Points of LLM Function Calling (2024).** Generates dialogues against a synthesized API pool, then uses both rule-based and model-based checks. An 8B checkpoint competes strongly on BFCL. The two-level check is a precedent for filtering training samples, with simulator-based outcome checks still needed for operator/threshold alignment. [Paper](https://arxiv.org/abs/2409.00920)
- **T18. LLM Agents Already Know When to Call Tools — Even Without Reasoning (2026).** Pre-generation hidden-state probes distinguish tool necessity across tested models and support steering that suppresses many calls with a small reported accuracy loss. This overlaps any broad claim of novelty from adding a small hidden-state head. Predicting necessity is simpler than choosing a grounded asset, comparison and prior-read index jointly. [Paper](https://arxiv.org/abs/2605.09252)
- **T19. Gorilla: Large Language Model Connected with Massive APIs (2023).** APIBench tests API generation across public machine-learning packages. Adding a document retriever helps the fine-tuned model adapt to changed documentation and reduces reported API hallucination. A tool catalog version change should be a semantic test and, when it changes token IDs, a cache divergence test. [Paper](https://arxiv.org/abs/2305.15334)
- **T20. ToolLLM: Facilitating Large Language Models to Master 16000+ Real-world APIs (2023).** Introduces API retrieval, synthetic tool chains, depth-first search over candidate trajectories and ToolEval. Search breadth buys additional opportunities at a compute cost. The local three-step interface could ablate a bounded second proposal against no retry, with all token work included. [Paper](https://arxiv.org/abs/2307.16789)
- **T21. Toolformer: Language Models Can Teach Themselves to Use Tools (2023).** Self-supervised call annotations let a language model invoke a calculator, search and related external tools. Outsourcing arithmetic supports the local split between language interpretation and comparison execution. The comparator can compute a declared predicate exactly while the proposer still chooses the wrong predicate. [Paper](https://arxiv.org/abs/2302.04761)
- **T22. ReAct: Synergizing Reasoning and Acting in Language Models (2022).** Interleaves generated reasoning and actions, observing gains on QA and interactive environments. It establishes that an observe-and-propose loop is standard prior art. For the edge board, the specific interface question is how much repeated input work the loop incurs and what an exact resume recovers. [Paper](https://arxiv.org/abs/2210.03629)

## Output constraints, semantics and decoding cost

- **T23. TruncProof: A Guardrail for LLM-based JSON Generation under Token-Length Constraints (2026).** Uses an LL(1) parser to approximate the tokens needed to complete valid JSON and constrains decoding against a hard output budget. Directly relevant to the repo's incomplete arrays at short generation caps. It supplies a stronger length-aware comparator than basic grammar masking. [Paper](https://arxiv.org/abs/2605.13076)
- **T24. Generating Structured Outputs from Language Models: Benchmark and Studies (2025).** JSONSchemaBench evaluates six constrained generation implementations across 10,000 schemas and distinguishes coverage, runtime and output quality. For the maintenance grammar, record supported schema features, emitted valid shape, semantic fidelity and full request cost as separate outcomes. [Paper](https://arxiv.org/abs/2501.10868)
- **T25. XGrammar: Flexible and Efficient Structured Generation Engine for Large Language Models (2024).** Prechecks context-independent vocabulary tokens, handles dynamic checks with a persistent stack and overlaps masking with inference. Its reported maximum engine speedup has a different denominator from board wall time. A relevant architecture baseline if an ARM grammar engine becomes part of the trace. [Paper](https://arxiv.org/abs/2411.15100)
- **T26. Guiding LLMs The Right Way: Fast, Non-Invasive Constrained Generation (2024).** DOMINO aligns constraints with subword tokens and uses precomputation and speculative decoding. Its experiments show that mismatched constraints can harm accuracy and that some aligned runs can beat unconstrained decoding latency. Preserve tokenizer identity when comparing constrained output and replay. [Paper](https://arxiv.org/abs/2403.06988)
- **T27. PICARD: Parsing Incrementally for Constrained Auto-Regressive Decoding from Language Models (2021).** Rejects inadmissible subwords using incremental parsing and improves T5 text-to-SQL results on Spider and CoSQL. It is a longstanding precedent for rejecting invalid formal continuations. Selecting one admissible tool argument or guard remains a model decision. [Paper](https://arxiv.org/abs/2109.05093)
- **T28. SynCode: LLM Generation with Grammar Augmentation (2024).** Uses an offline DFA mask store to preserve admissible tokens under a context-free grammar, eliminating syntax errors on its JSON experiment. Its offline compilation fits the fixed local wire grammar. Catalog-conditioned masks and mask storage still need measurement on target. [Paper](https://arxiv.org/abs/2403.01632)
- **T29. Efficient Guided Generation for Large Language Models (2023).** The Outlines approach indexes model vocabulary against finite-state transitions, reducing per-step work for regex and grammar guidance. This is an established comparator for a fixed-schema ARM path. Compile cost and in-memory vocabulary index size belong in the resource budget. [Paper](https://arxiv.org/abs/2307.09702)
- **T30. Grammar-Aligned Decoding (2024).** Shows that local token masks can distort the model distribution conditional on a grammar and develops adaptive sampling with approximate expected futures. Calibration and greedy output parity have different goals. Fit any semantic confidence threshold for the actual decoding policy and budget. [Paper](https://arxiv.org/abs/2405.21047)
- **T31. Grammar-Constrained Decoding for Structured NLP Tasks without Finetuning (2023).** **Selected sections.** Input-dependent grammars improve extraction, disambiguation and constituency parsing. The direct transfer is dynamic valid domains for current asset/receipt IDs. A schema generated from public input can exclude impossible references while allowing the wrong listed asset. [Paper](https://aclanthology.org/2023.emnlp-main.674/)
- **T32. IterGen: Iterative Semantic-aware Structured LLM Generation with Backtracking (2024).** **Selected sections.** Maintains grammar-symbol positions, decoding trace and coherent KV state across forward and backward calls. Its SQL example resamples invalid column and table names and the decoder can penalize previously rejected tokens. This is a close comparator for logical rollback. The proposed board experiment instead holds the sampling policy fixed and checks physical memory state after a failed command. [Paper](https://arxiv.org/html/2410.07295#S3)
- **T33. Synchromesh: Reliable Code Generation from Pre-Trained Language Models (2022).** Combines target-similarity retrieval with decoding constraints over scope, types and contextual rules for SQL, Vega-Lite and SMCalFlow. Its semantic constraints already extend beyond grammar. A local receipt-aware constraint could guarantee a prior evidence reference exists, with ground-truth request fidelity scored separately. [Paper](https://arxiv.org/abs/2201.11227)

## Conditional language, intent and test design

- **T34. Language to Code: Learning Semantic Parsers for If-This-Then-That Recipes (2015).** **Selected sections.** Maps community descriptions to trigger/action recipes from IFTTT, where channels can expose sensors and controllers. This is the direct historical semantic predecessor. The local problem adds typed measurement comparisons, failed observations and simulator replay against a small state set. [ACL paper](https://aclanthology.org/P15-1085.pdf)
- **T35. Improved Semantic Parsers For If-Then Statements (2016).** **Selected sections.** On the full IFTTT test, the neural/logistic ensemble reaches 42.55% full-tree accuracy against 34.50% for the previous aligned parser. It analyzes swapped triggers/actions and missed cues. The logistic model slightly beats the neural model by itself, supporting a prospectively scored cheap learned control for maintenance. [ACL paper](https://aclanthology.org/P16-1069.pdf)
- **T36. Semantic Evaluation for Text-to-SQL with Distilled Test Suites (2020).** Selects databases on which to compare query denotations and documents false negatives from the existing metric. Transfer this as targeted plant-state evaluation. Generate states that distinguish equal-boundary operators and erroneous guard/asset alternatives. Denotation agreement over sampled states is weaker than equality for every state. [ACL paper](https://aclanthology.org/2020.emnlp-main.29/)
- **T37. Evaluating Models' Local Decision Boundaries via Contrast Sets (2020).** Small meaningful edits that often change the expected label expose large accuracy drops across ten datasets. Have an independent author introduce minimal opposite-comparator and same-comparator paraphrase pairs, and score correctness on both sides. [ACL paper](https://aclanthology.org/2020.findings-emnlp.117/)
- **T38. Beyond Accuracy: Behavioral Testing of NLP Models with CheckList (2020).** A capability-by-test matrix uncovers bugs in already evaluated models. It motivates distinct minimum-functionality, invariance and expected-change tests for the local operator/asset/receipt contract. Keep this matrix separate from randomly sampled workload performance. [ACL paper](https://aclanthology.org/2020.acl-main.442/)
- **T39. Measuring Compositional Generalization: A Comprehensive Method on Realistic Data (2019).** CFQ uses atom/compound divergence to isolate compositional shifts and finds strong accuracy degradation as compound divergence grows. Keep known operators, actions and asset types in training while holding out specific operator×action×dependency combinations and entire language families for evaluation. [Paper](https://arxiv.org/abs/1912.09713)
- **T40. An Evaluation Dataset for Intent Classification and Out-of-Scope Prediction (2019).** CLINC150 adds explicit OOS examples and shows a gap between in-scope accuracy and OOS detection. This is the source lineage for the repo's R5 intent comparisons. Separate unsupported operations from supported operations with missing fields, conflicting references or uncertain authorization. [ACL paper](https://aclanthology.org/D19-1131/)
- **T41. Towards Scalable Multi-domain Conversational Agents: The Schema-Guided Dialogue Dataset (2019).** SGD includes more than 16,000 multi-domain conversations and describes services with schemas rather than one static ontology. Its unseen service framing is useful for an asset catalog swap. Local per-slot F1 does not directly measure complete dialogue state or guarded-plan correctness. [Paper](https://arxiv.org/abs/1909.05855)
- **T42. Semantic Parsing for Task Oriented Dialog using Hierarchical Representations (2018).** TOP makes nested intents and slots explicit and shows that constituency-style parsing can beat sequence generation in its setting. A typed tree for compare/read/action relations could preserve dependencies that independent categorical argmaxes lose. [Paper](https://arxiv.org/abs/1810.07942)
- **T43. Efficient Intent Detection with Dual Sentence Encoders (2020).** Dual sentence encoders deliver strong few-shot intent accuracy with brief CPU training and introduce BANKING77. This supports a small encoder as a low-cost prospective semantic control, with complete numeric arguments and episode accuracy measured separately. [Paper](https://arxiv.org/abs/2003.04807)

## Scope for a board experiment

The tool literature already offers interactive proposal, stateful execution, bounded JSON, typed constraints, hidden-state probes, paired abstention and recoverable tool faults. The immediate board opportunity is a different hypothesis about a single decoder and its memory owner. If a post-command failure leaves a proven, still-valid prefix in DDR, the service may retain that prefix, replay a suffix and recover exactly relative to a cold retry. Unknown drainage, reset or identity change must follow an explicit fail-closed policy. The distinction needs proof or instrumentation at the write interface. A Python exception category has no independent evidence about writes still outstanding. The v9d head-major cache scatters each token position across layer, K/V and head rows, so the protected frontier is a token position and its corresponding set of byte ranges. [v9d cache layout](../../hls/qwen_decoder_v9d/qwen_decoder.cpp)

Use a seeded board workload and a second frozen workload adapted from a pinned multi-turn tool benchmark, provided the prompt lengths fit the tested board envelope. Freeze prompt IDs, receipts, request order, budgets and fault schedules across invalidate-all and selective recovery policies. Cross clean runs, proven failures before command issue, post-command failures with demonstrable suffix-only writes, unknown drainage, and reset/identity change. Measure true prefix depth, recomputed tokens, first resumed-token and full generated-ID parity against a matched cold reference, retry latency including proof/cleanup, and completion within declared deadline scenarios. Report each class separately and disclose injected fault mix. Compare state bytes or an appropriate independent oracle where the platform permits observation. Scope initial injections to inference before tool dispatch. The current service commits KV before executing a validated call, so a fault after dispatch can require tool-level idempotency or a durable receipt even if the cache can be safely resumed. A small deterministic closed-loop mock can illustrate integration by advancing simulator state on an admissible model output. Fixed trace replay independently measures board recovery. [v16 service](../../src/sysone/v2/qwen_arm_service_v16.py)

A separate semantic contribution would need independent natural-language authors, new asset and language families, compositional holdouts and prospective controls. The existing data can remain a regression and diagnostic suite. Include an authored-rule baseline and cheap learned baseline, distinguish syntax and grounded-plan agreement, and compare selective error at matched actionable coverage. T05–T08, T18, T23 and T34–T39 materially narrow the novelty of that path.
