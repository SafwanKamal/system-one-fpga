# RC1.2 shipped: v9g + cost-aware lossless speculation in the default service (2026-11-20)

## Result

RC1.2 is live on the KR260 as the default `sysone-rc1.service`, installed at 07:01Z on boot
62097330. On the 21 tool queries, RC1.1 against RC1.2 on the same boot (cache reset per query):

| | RC1.1 (v9e, n-gram + gate) | RC1.2 (v9g, cost-aware drafter) | Speedup |
|---|---|---|---|
| Output | | 21/21 identical generated ids and tool calls | |
| Decode, total | 27.2 s | 13.5 s | **2.02x** |
| Decode, median | 1.18 s | 0.63 s | 1.88x |
| Prefill, total | 27.5 s | 26.9 s | 1.02x (short prompts) |
| End-to-end, median | 2.50 s | 1.92 s | **1.30x** |

The rollback drill passed: disabling RC1.2 gives RC1.1 on v9e, and enabling it again gives
RC1.2. Data is in `build/v2/rc1-2/board/bench-compare.json` and `build/v2/rc12-run/results/`.

## What changed on the board

The bundle is `firmware/rc1_2/`, built by `scripts/v2/package_rc12.py`. It is a second
systemd drop-in, `20-rc12.conf`, layered on RC1.1:
- **Before start**, `rc12_image.py up` switches the FPGA from v9e to v9g. The switch takes
  about 2 s, is idempotent, and leaves the DMA table unchanged.
- **The service** is `spec_service_rc12.py`: the RC1 session on v9g, with one batched head
  scan per verify pass and the cost-aware drafter, which needs no gate.
- **After stop**, the FPGA switches back to v9e. v9e stays the resting image, so the boot
  initializer, the drain procedure and the pilot tools are unchanged.

The sealed RC1 package is not modified. RC1.2 serves from a copy of it that adds the v9g app
directory.

## Exactness basis

The emitted tokens are the engine's greedy tokens. The earlier board runs showed this:
- v9g pilot: 181/181 identical to the v9e records;
- drafter board check: 181/181 identical, with replay statistics exact.

The ship bench adds 21/21 identical outputs through the live service.

## Not yet verified

- **Behaviour across a reboot.** The boot path is the unchanged initializer, then the same
  `ExecStartPre` that the restarts exercised.
- **Long-prompt service traffic.** The service accepts tool queries only; the long-context
  gains were measured in the pilots, with prefill 1.22x on v9g against v9f.
